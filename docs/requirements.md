# 要件定義

## 概要
ユーザーがアップロードした画像とタイトルをもとに、AIが「日常の貴重さ」を判定してトレーディングカードを生成するWebアプリケーション。
「日常を切り取ってカードにする」体験を提供する。将来的な対戦機能の実装も見据え、拡張性の高い設計を行う。

## 技術スタック
詳細は [tech_stack.md](./tech_stack.md) を参照。


## 機能要件

### 1. カード生成機能
- **入力**: 画像アップロード、タイトル入力、**画像の説明（状況や背景など）**
- **AI処理**:
    - 画像とユーザー入力（説明）の内容を解析し、「貴重度（レアリティ）」を判定
    - 貴重度が高い（例：子供の誕生）ほど、ステータスを高く設定
    - 貴重度が低い（例：ラーメン）ほど、ステータスを低く設定
    - 画像とタイトル、説明に合わせたフレーバーテキストとカード名を生成
- **出力**: カード画像（Canvas APIを用いて描画・表示）

### 2. カードパラメータ構成（案）
- **名前**: タイトルと画像を元にAIが生成
- **レアリティ**: **★1〜★10**（貴重度）
- **属性**: 写真の雰囲気（熱血=炎、冷静=水、日常=無、など）
- **種族**: 人間、料理、風景、機械、動物、イベントなど
- **攻撃力/守備力**: 0〜5000（貴重度に比例）
- **フレーバーテキスト**: 写真の状況を、過剰にドラマチック、あるいはシニカルに表現したテキスト。
    - 例：「太古より伝わりし...」「その一撃は世界を揺るがす...」といったTCG特有の壮大な言い回し
    - 例：日常の些細な出来事（ラーメンを食べる等）を、あたかも歴史的転換点や神話の一部であるかのように大げさに語るシュールな表現
    - ユーザー入力の「画像の説明」をベースにしつつ、飛躍した解釈を加える
- **効果**: なし（バニラカード）

### 3. ページ構成
- **生成ページ**: 画像アップロードと生成実行
- **一覧ページ**: 保存済みカードのグリッド表示
- **詳細ページ**: カードの拡大表示、エクスポート・プリント操作

### 4. その他機能
- **保存**: 生成データをIndexedDBに保存
- **エクスポート**: カードを画像としてダウンロード
- **プリント**: L判などのサイズで印刷できるレイアウト表示（1枚ずつ）

## 非機能要件
- **拡張性**:
    - 将来的な対戦ルールの追加や変更に柔軟に対応できるよう、AIへのプロンプト（指示）を疎結合に設計する。
    - ルール定義や評価基準をプロンプト内でモジュール化し、差し替え可能にする。
