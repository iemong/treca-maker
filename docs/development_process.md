# 開発プロセス

## 開発手法
**TDD (Test Driven Development)** を採用する。

### 基本フロー
1.  **Red**: 失敗するテストを書く（仕様の明確化）
2.  **Green**: テストを通すための最小限の実装を行う
3.  **Refactor**: コードを整理する

### 具体的な進め方
- ロジック部分（AIレスポンスのパース、パラメータ計算、プロンプト構築など）から優先的に実装を進める。
- UIコンポーネントについても、可能な限りロジックを分離してテスト可能にする。
- GitHub Flow等のブランチ戦略を採用する場合（今回は個人開発想定だが）、機能ごとにブランチを切って作業することを推奨。
